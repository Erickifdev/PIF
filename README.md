PIF
Um espaço de estudos para organizar matérias, guardar perguntas e praticar no seu ritmo.

 O que dá para fazer

- Criar matérias e organizar cada uma por assuntos.
- Adicionar perguntas e respostas individualmente ou colar um bloco com várias.
- Revisar as perguntas encontradas antes de salvá-las e escolher se são abertas ou fechadas.
- Praticar: escrever respostas para perguntas abertas e conferir as fechadas.
- Apagar matérias, assuntos e perguntas.

 Como usar

Abra o site, crie uma matéria e adicione um assunto. Depois, cadastre perguntas e respostas ou use **Colar bloco** para importar várias de uma vez. Entre em **Praticar** para começar uma sessão.

Para importar, use um formato como:

```text
Pergunta: O que é fotossíntese?
Resposta: É o processo pelo qual as plantas produzem seu alimento.

Pergunta: A água ferve a 100 °C?
Resposta: Sim.
```
